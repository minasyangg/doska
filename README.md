# Доска для онлайн-занятий

Бесконечное полотно с рукописным вводом и синхронизацией в реальном времени.
Несколько досок, адаптивная сетка, вставка скриншотов через Ctrl+V.

## Установка на своём компьютере

Нужен Node.js 18 или новее — https://nodejs.org

```bash
npm install
npm start
```

Откройте http://localhost:8080 — увидите список досок. Так проверяется всё,
кроме подключения ученика с другого компьютера: для этого нужен раздел
«Размещение в интернете».

## Что где

```
server.js          сервер: раздача клиента, список досок, картинки, синхронизация
public/index.html  клиент целиком: движок пера, интерфейс, сеть
data/boards/       содержимое досок в JSON
data/files/        вставленные картинки
data/index/        список досок каждого преподавателя
```

Папка `data/` создаётся сама. Резервная копия — это просто копия этой папки.

## Работа с досками

**Ключ доступа.** При первом открытии браузер получает случайный ключ, и к нему
привязывается ваш список досок. Пароля и почты нет — намеренно, чтобы не
разводить лишнего. Нажмите «Ключ доступа», чтобы скопировать его и открыть те
же доски на планшете. Ученикам ключ давать нельзя: он даёт права преподавателя.

**Ссылка ученику** — кнопка в списке досок и на самой доске. В ней нет ключа,
поэтому вошедший по ней получает права ученика: рисует, но не может очистить
доску или стереть чужое.

**Права преподавателя:** запретить ученикам рисовать, стереть чужие записи,
очистить доску, переименовать её. Ученик может включить кнопку «Следовать» —
тогда его экран повторяет вашу область просмотра. На бесконечном полотне это
выручает: ученик не потеряется, пока вы что-то объясняете в стороне.

Звука и видео здесь нет намеренно. Держите параллельно привычный звонок.

## Управление

| Действие | Как |
|---|---|
| Масштаб | колесо мыши, кнопки −/+ справа снизу, клавиши +/− |
| Панорама | Shift+колесо, пробел с перетаскиванием, средняя кнопка, инструмент «рука» |
| Вставить скриншот | Ctrl+V, либо перетащить файл картинки на доску |
| Двигать и растягивать картинку | инструмент «выделить» (4), тянуть за углы |
| Удалить картинку | выделить и нажать Delete |
| Фон: клетка → точки → линейка → чистый лист | кнопка сетки в панели или клавиша G |
| Инструменты | 1 карандаш, 2 маркер, 3 ластик, 4 выделить, 5 рука |
| Отменить, вернуть | Ctrl+Z, Ctrl+Shift+Z |
| В начало координат | клавиша 0 или кнопка ⌂ |

Сетка адаптивная: шаг клетки сам меняется при масштабировании и остаётся
удобным для глаза, мелкая клетка проявляется плавно. Настройка фона своя
у каждого участника и на общую доску не влияет.

Картинки всегда рисуются под рукописным текстом. Это сделано специально:
вставленный скриншот не закроет то, что уже написано, и можно спокойно
писать поверх него.

## Размещение в интернете

Сервер должен работать по HTTPS: браузеры разрешают защищённые сокеты
(`wss://`) только со страниц, открытых по `https://`.

### Готовый хостинг

Render, Railway, Fly.io. Схема одинаковая: положите папку в репозиторий GitHub,
создайте Web Service, команда установки `npm install`, команда запуска
`npm start`. Порт сервер берёт из переменной `PORT` — это уже учтено.

Два подводных камня на бесплатных тарифах:

1. Сервис засыпает при простое и просыпается 20–50 секунд. Открывайте доску
   за минуту до урока или берите платный тариф (примерно 5–7 $ в месяц).
2. Файловая система сбрасывается при каждом обновлении, и папка `data/`
   исчезнет вместе с досками и картинками. Подключите постоянный диск
   (persistent disk) и задайте переменную окружения `DATA_DIR=/data`.
   Без этого шага доски не переживут следующий деплой.

### Свой сервер

VPS за 4–6 € в месяц, домен и Caddy как обратный прокси — сертификат он
получает сам. Файл `/etc/caddy/Caddyfile`:

```
doska.example.com {
    reverse_proxy localhost:8080
}
```

Сервер держать живым через `pm2 start server.js` или юнит systemd.
Место под картинки: считайте 1–3 МБ на скриншот.

## Чего пока нет

- Текста с клавиатуры, фигур, стрелок, линеек.
- Выделения и перемещения рукописных линий — двигать можно только картинки.
- Редактора формул.
- PDF на доске (вы сказали, что не нужен).
- Ластик удаляет линию целиком, а не её часть.
- Отмена локальная: Ctrl+Z убирает ваше последнее действие. Если двое
  одновременно пишут в одном месте, порядок объектов может слегка разойтись.
  Лечится переходом на CRDT (Yjs) — это отдельная работа.
- Комфортно примерно до 10–15 участников и десятков тысяч объектов на доске.

## Если что-то не работает

**Список досок не загружается.** Сервер не запущен или занят другой порт.
Проверьте вывод `npm start` — там печатается адрес.

**Ученик видит доску, но рисунки не появляются.** Почти всегда это HTTPS:
страница открыта по `https://`, а сокет пытается идти по `ws://`. Проверьте,
что прокси пропускает WebSocket (в Caddy — по умолчанию пропускает).

**Скриншот не вставляется.** В буфере должна быть именно картинка, а не файл
из проводника. Поддерживаются PNG, JPEG, WebP, GIF до 16 МБ.
