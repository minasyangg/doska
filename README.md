# Доска для онлайн-занятий

Бесконечное полотно с рукописным вводом и синхронизацией в реальном времени.
Учитель и ученик заходят своими аккаунтами mcko-app, доски живут, пока их не
удалят, у каждой — свой список участников и своё хранилище картинок.

## Установка на своём компьютере

Нужен Node.js 20.6 или новее — https://nodejs.org

```bash
npm install
cp .env.dev.local.example .env.dev.local   # и заполнить, см. ниже
npm run dev
```

Откройте http://localhost:8080 — попадёте на экран входа.

### Переменные окружения

`npm run dev` читает их из `.env.dev.local` (файл в `.gitignore`, шаблон рядом).
На сервере то же самое задаётся обычными переменными окружения и запускается
через `npm start`.

| Переменная | Зачем |
|---|---|
| `SUPABASE_URL` | Проект Supabase, общий с mcko-app. Доска не хранит в нём ничего своего сверх таблиц `doska_*`. |
| `SUPABASE_ANON_KEY` | Publishable-ключ (`sb_publishable_…`). Именно он, а не legacy anon: legacy в проекте отключён. |
| `SESSION_SECRET` | Ключ шифрования сессий, от 32 символов. Без него доска поднимется на временном ключе и все входы слетят при перезапуске. |
| `DOSKA_SSO_SECRET` | Общий секрет с mcko-app для перехода по кнопке «Доска». Без него работает только вход почтой и паролем. |
| `PORT` | По умолчанию 8080. Должен совпадать с `DOSKA_URL` в mcko-app. |
| `DATA_DIR` | Куда класть доски и картинки. Пусто — `./data` рядом с `server.js`. |
| `TRUST_PROXY=1` | За обратным прокси: брать протокол из `X-Forwarded-Proto`, иначе кука не получит флаг `Secure`. |

## Что где

```
server.js          сервер: маршруты, комнаты, синхронизация
lib/gotrue.js      пять запросов к Supabase Auth (вместо SDK)
lib/db.js          БД mcko-app через PostgREST — всегда токеном пользователя
lib/session.js     сессии: кука + зашифрованные токены на диске
lib/capability.js  кто что может делать с доской
public/index.html  клиент целиком: движок пера, интерфейс, сеть
data/boards/       содержимое досок в JSON
data/files/        вставленные картинки, по каталогу на доску
data/sessions/     сессии (зашифрованы AES-256-GCM)
```

Папка `data/` создаётся сама. Резервная копия — это её копия **плюс** дамп
таблиц `doska_*` в Supabase: без них доска не поймёт, кому что принадлежит.

## Вход и права

Вход общий с mcko-app: та же почта и тот же пароль. Своей регистрации у доски
нет — аккаунты заводит mcko-app.

Токены Supabase в браузер не попадают вообще. При входе доска заводит свою
сессию: в куке только её идентификатор (`HttpOnly`, `SameSite=Lax`, `Secure`
под HTTPS), а пара токенов лежит на сервере зашифрованной. Своя пара, а не
проброшенная из mcko-app, — потому что ротация refresh-токенов включена, и
общий токен означал бы, что доска и mcko-app гасят сессии друг друга.

Из mcko-app есть бесшовный переход: кнопка «Доска» у учителя и ссылки в
кабинете ученика ведут на `/api/doska/open`, оттуда — одноразовый тикет на
60 секунд, и человек попадает на доску уже вошедшим.

**Права на доске** разрешаются так (первое подходящее):

| Кто | Что может |
|---|---|
| Владелец (учитель, создавший доску) | всё: рисовать, стирать любое, переименовывать, запрещать рисование, менять доступ, удалить доску |
| Участник с уровнем «рисует» | рисовать, двигать и стирать своё; чужое — только если владелец разрешил |
| Участник с уровнем «смотрит» | смотреть, масштабировать, включить «Следовать» |
| Админ организации | видит все доски организации и открывает их только на просмотр |
| Гость по ссылке | смотреть или рисовать — как выбрал владелец; по умолчанию гостевая ссылка выключена |
| Все остальные | ничего: доска не открывается |

Всё это проверяется не доской, а RLS в Supabase (`041_doska_boards.sql`):
доска ходит в базу токеном самого пользователя и сервисного ключа не имеет.
Добавить в участники можно только своего ученика — это проверяет
`check_student_owned_by_auth`, та же функция, что и в остальном mcko-app.

Права перепроверяются раз в минуту, поэтому отзыв участника доходит до
открытой вкладки в течение минуты, а не к концу занятия.

Звука и видео здесь нет намеренно. Держите параллельно привычный звонок.

## Управление

| Действие | Как |
|---|---|
| Масштаб | колесо мыши, кнопки −/+ справа снизу, клавиши +/− |
| Панорама | Shift+колесо, пробел с перетаскиванием, средняя кнопка, инструмент «рука» |
| Вставить скриншот | Ctrl+V, либо перетащить файл картинки на доску |
| Двигать, растягивать, вращать объект | инструмент «выделить» (4), тянуть за ручки |
| Дублировать выделенное | Ctrl+D |
| Удалить выделенное | Delete |
| Фон: клетка → точки → линейка → чистый лист | кнопка сетки или клавиша G |
| Инструменты | 1 карандаш, 2 маркер, 3 ластик, 4 выделить, 5 рука, 6 фигура |
| Фигуры и линии | R прямоугольник, O эллипс, L линия, A стрелка, N ломаная, C кривая, M многоугольник; Enter — завершить, Esc — отменить |
| Отменить, вернуть | Ctrl+Z, Ctrl+Shift+Z |
| В начало координат | клавиша 0 или кнопка ⌂ |

Сетка адаптивная: шаг клетки сам меняется при масштабировании. Настройка фона
своя у каждого участника и на общую доску не влияет.

Картинки всегда рисуются под рукописным текстом — вставленный скриншот не
закроет то, что уже написано.

## Размещение в интернете

Сервер должен работать по HTTPS: браузеры разрешают защищённые сокеты
(`wss://`) только со страниц, открытых по `https://`. Куке сессии флаг `Secure`
тоже нужен, а за прокси для этого понадобится `TRUST_PROXY=1`.

### Готовый хостинг

Render, Railway, Fly.io: команда установки `npm install`, запуск `npm start`,
порт из `PORT`. Два подводных камня на бесплатных тарифах:

1. Сервис засыпает при простое и просыпается 20–50 секунд.
2. Файловая система сбрасывается при обновлении, и `data/` исчезнет вместе с
   досками, картинками и сессиями. Подключите постоянный диск и задайте
   `DATA_DIR=/data`.

### Свой сервер

VPS, домен и Caddy как обратный прокси — сертификат он получает сам:

```
doska.example.com {
    reverse_proxy localhost:8080
}
```

Держать живым через `pm2 start server.js` или юнит systemd. Место под картинки:
считайте 1–3 МБ на скриншот, на доску отведено 200 МБ.

## Чего пока нет

- Текста с клавиатуры и редактора формул.
- PDF на доске.
- Ластик удаляет линию целиком, а не её часть.
- Отмена локальная: Ctrl+Z убирает ваше последнее действие. Если двое
  одновременно пишут в одном месте, порядок объектов может слегка разойтись.
  Лечится переходом на CRDT (Yjs) — это отдельная работа.
- Комфортно примерно до 10–15 участников и десятков тысяч объектов на доске.

## Если что-то не работает

**Не пускает по правильному паролю.** Проверьте `SUPABASE_URL` и
`SUPABASE_ANON_KEY`: ключ должен быть publishable (`sb_publishable_…`), legacy
anon в проекте отключён и отвечает 401 с пустым телом.

**Вход слетает после каждого перезапуска.** Не задан `SESSION_SECRET` —
доска работает на временном ключе и не может расшифровать старые сессии.

**Кнопка «Доска» в mcko-app ведёт на экран входа.** Не совпадают
`DOSKA_SSO_SECRET` на двух сторонах, либо тикет протух: он живёт 60 секунд и
гасится при первом использовании.

**Ученик видит доску, но рисунки не появляются.** Почти всегда это HTTPS:
страница открыта по `https://`, а сокет идёт по `ws://`. Проверьте, что прокси
пропускает WebSocket (Caddy пропускает по умолчанию).

**Скриншот не вставляется.** В буфере должна быть именно картинка, а не файл
из проводника. Поддерживаются PNG, JPEG, WebP, GIF до 16 МБ.
